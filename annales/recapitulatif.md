# Annales d'informatique MP (2011–2026) — récapitulatif

Sujets d'écrit de la filière MP (plus l'informatique TSI du CCINP), classés par matière (ITC/IPT ou option informatique), puis par thème et par concours. Source des énoncés : doc-solus.fr, wikiprepa.fr (CCINP option 2011–2015), concours-commun-inp.fr (TSI).

Les entrées « [Maths] » sont des extraits (pages indiquées) des sujets de mathématiques contenant des questions d'informatique commune.

Organisation du dossier :

- `<matière>/par-concours/<concours>/` : les PDF ;
- `<matière>/par-theme/<thème>/<concours>/` : liens symboliques vers ces PDF (un sujet multi-thèmes apparaît dans chacun de ses thèmes).

Thème en **gras** = thème principal du sujet.

## Remarques et lacunes

- **XENS Info B** (2011–2013) : épreuve « MP hors option + PC » antérieure à IPT, rangée en ITC. Pas d'Info B 2014 ni 2020 disponible ; pas d'Info A 2026 disponible.
- **CCINP option** : depuis 2015, certaines parties sont à traiter en Python (programme ITC/IPT) ; elles sont signalées « Python, ITC » dans les fiches. Le sujet reste classé en option.
- **CCINP option 2016–2019** : absents (non disponibles sur doc-solus, et wikiprepa bloque le téléchargement automatique).
- **E3A** : pas d'épreuve d'option informatique MP disponible après 2011.
- **CCINP, ITC en MP** : pas d'épreuve dédiée ; l'ITC apparaît dans les sujets de mathématiques (extraits « [Maths] », 2015–2026). Pas de question d'informatique trouvée dans : Maths 1 2015–2017, 2019, 2024, 2025 ; Maths 2 2018, 2020–2023, 2026.
- **Centrale, ITC depuis 2023** : les sujets de mathématiques 2022–2026 ne contiennent qu'une question Python (Maths 2 2025, Q9). Le Python apparaît aussi en physique (Physique 2 2025) ; les sujets de physique 2022–2024 n'ont pas été examinés (texte non extractible).
- **CCINP TSI** : sujets 2015 et 2019–2026 ; 2016–2018 non publiés sur le site du concours (rapports seulement). Le sujet daté 2020 ici est publié sous le nom `informatique_TSI5IN.pdf` dans le dossier 2019 du site, mais porte « Session 2020 ».
